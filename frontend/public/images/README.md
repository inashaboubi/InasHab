# Images pour le Portfolio

## Images à ajouter :

1. **hero.jpg** - Votre photo pour la section hero (format recommandé: 400x500px ou plus)

2. **taskflow.png** - Capture d'écran du projet TaskFlow
3. **fitlife.png** - Capture d'écran du projet FitLife
4. **ecommerce.png** - Capture d'écran du projet E-commerce

## Instructions :

- Placez vos images dans ce dossier
- Les formats recommandés : JPG, PNG, WebP
- Pour une qualité optimale, utilisez des images d'au moins 800px de largeur
- Les captures d'écran des projets devraient montrer l'interface principale de l'application
